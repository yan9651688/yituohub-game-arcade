## 开始

1. 完整解压压缩包。
2. 打开最外层 `index.html`，选择游戏卡片。
3. 也可以直接打开 `games/游戏目录/index.html`。左上角链接回到游戏厅。

无需安装、联网、登录或构建。不要只复制一个 HTML 文件，需保留其余 JS、CSS 及目录结构。若手机文件管理器只显示源码，请在浏览器中打开，或把完整目录部署到静态网站。网页不会自动把文件安装到桌面。

## 通用操作

- 键盘操作与每款游戏的屏幕说明对应。
- 左键是游戏画面内的主要动作，网页按钮不会同时触发攻击。
- 手机/平板使用各游戏的触屏按钮。打砖块可以拖动球板。
- 各游戏有暂停、重开、声音开关和规则说明。失焦/隐藏页面会暂停，回来后手动继续。
- 最高分等记录只保存在当前浏览器。浏览器禁用本地存储时仍可游玩；清理数据后记录可能消失。
- 分类筛选与“上次玩到这里”只影响入口，不会删掉游戏记录。

## 静态部署

完整上传目录至网站即可，入口是根目录 `index.html`。使用相对链接，可放在网站子目录。游戏运行不依赖字体、CDN、在线接口或外部图片；参考文档的来源链接需要网络。

本机预览也可以运行：

```
python3 -m http.server 8000 --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:8000/`。

## 开发与验证

各游戏的逻辑核心可由 Node 加载，不需要第三方依赖。测试和资料随包附带；并非浏览器运行必需。可在安装 Node 20 或更新版本后运行 `node tests/run-all.cjs`。详细验证范围见 `QA.md`。

UI 为独立原创像素卡带风格。所有游戏都能单独运行，不存在“即将推出”的占位入口。
