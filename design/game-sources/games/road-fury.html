RIDER'S HANDBOOK

边打边跑，以战养战。

巡回赛包含 12 条独立赛道，前 3 名解锁下一关。自由试跑开放全部赛道。对手头顶闪红时即将出手，拉开距离或抢先攻击可让他失手。

领跑的三名对手不再互相缠斗；你接近时会主动靠近出手。第一名恢复较远的起跑位置，氮气与战斗奖励沿用 3.3。

A / D 或 ← → 转向W / S 油门 / 刹车J 向左挥棍K 向右挥棍空格 自动攻击近侧SHIFT 氮气爆发C 切换自动油门P / ESC 暂停

有效命中：氮气 +12、战斗护甲 +8（最多 40）；打断红色蓄力额外奖励。累计三次命中蓄满重击，下一次命中造成 60 伤害，打空不消耗。击倒：维修 +18、氮气 +20，并储存一次 3 秒免费冲刺（最多一份，按 Shift 主动使用，松开提前结束）。同一返场车手收益递减。护甲、重击和冲刺库存本关内保留，重跑重置。

默认自动油门开启，按 S 刹车。按住 J / K / 空格近身攻击时轻微匹配对手车速，方便连续交手；转向仍由你控制，松手、远离或 Shift 立即脱离。三个难度只改变接敌、反击与攻击频率，车速、生命、伤害、交通与奖励相同。七名对手仍在前方分散行驶，领跑者起始距离已缩短。警摩从路肩起步追缉，不计入排名；拉开足够距离持续 3 秒可脱离，或用 J / K 击退。低速或摔车时，被警摩贴近并持续截停才会被捕；高速碰一下不会被捕。严重撞车会短暂倒地，随后自动起步。
