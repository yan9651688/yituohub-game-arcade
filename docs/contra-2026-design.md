# 魂斗罗 2026 · 八关战役设计

这款浏览器游戏沿用《魂斗罗》FC 版本的八关顺序、横向／纵向／纵深三类推进方式，以及各关的代表场景。角色、场景几何、关卡坐标、灯光和程序均为本项目重新制作。它是向原作致敬的现代浏览器改编，不宣称与原版逐像素、逐坐标、逐帧一致，也不是 KONAMI 官方作品。

关卡数据位于 [levels.js](../public/game-arcade/games/contra2026/levels.js)。文档中的 Boss 图谱记录八种战斗的设计意图，具体攻击实现以游戏程序为准。

## 画面方向

参考游戏厅现有的《智械前线》《雷霆战翼》：有棱面的立体角色、块状地形、明确的明暗面、远景雾、低饱和环境和少量高亮弹道。通过真实几何的体积和光照延续同一游戏厅的视觉气质。每关有独立的配色和场景构件，避免只替换天空颜色。

- 丛林以浅蓝日光天空、灰绿土层、苔绿地表和暖色枪火为主，河谷与桥梁形成景深。
- 基地使用冷灰金属、蓝青灯带和强透视走廊，深层基地逐步转为暖色警戒灯。
- 瀑布使用明亮浅蓝天空、蓝灰岩壁、浅青水流和高差层次，让垂直行进方向一目了然。
- 雪原使用冷灰蓝装甲、浅色积雪与暖色爆炸；轮廓应在雪雾中保持清楚。
- 工厂以暖日光天空、砂色金属结构与橙色热源突出危险区域；机库使用蓝灰天空、钢蓝结构与黄黑机械构件。
- 巢穴使用暗紫红、肉色结构和浅黄绿能量，将前七关的人造设施过渡为有机空间。

## 八种 Boss 图谱

Boss 的外形、名称及攻击节奏是本项目的改编设计。每场战斗应让玩家能读懂危险的起点、方向和空隙；攻击前有可见预兆，命中后有清楚反馈。

| 类型 / 数据 ID | 外形与空间 | 主要攻击图谱 | 玩家应对与阶段变化 |
| --- | --- | --- | --- |
| 装甲防壁 / `gate` | 立在丛林出口的分层装甲门，左右炮位围绕中间动力核 | 低位横射与中心扇形弹分拍出现 | 先读懂横弹高度，再利用跳跃避开；残血增加齐射密度，保留换位时间 |
| 独眼守卫 / `sentinel` | 基地尽头的单眼主机与两侧炮架 | 中心瞄准射击，左右炮架形成交叉封锁 | 横向移动使瞄准落空，集中射击暴露核心；瞄准提示先于弹体 |
| 瀑布巨像 / `hydra` | 顶部岩台上的多首机械巨像，头部与手臂组成清楚轮廓 | 上部扇形弹配合低位地面威胁 | 在平台上保留左右走位空间；不同发射口轮换，避免所有方向同时封死 |
| 双生机神 / `twins` | 基地尽头左右对称的双头装甲系统 | 两个高位节点交替开火，低位炮台补射 | 选择一侧集中输出，再处理另一侧；轮替节奏要能被观察与预判 |
| 极地浮空舰 / `hover` | 雪原上空的宽体战舰，底部引擎和火炮分层 | 悬停散射、定点下投与横向换位 | 依据影子和投放预警换位；不要让飞行高度超出默认武器可攻击范围 |
| 熔炉巨兵 / `titan` | 具有明显双腿与大型前臂的工业机械兵 | 短距离迫近、拳击预备与火力齐射 | 近身前拉开距离，利用攻击后停顿输出；地面留足后退空间 |
| 最终防壁 / `fortress` | 占据机库出口的高大门体，多层炮位包围核心 | 上下交替齐射、侧向追踪弹与核心脉冲 | 保留高低躲避选择；武器颜色与装甲颜色区分，核心命中反馈集中 |
| 脉冲之心 / `heart` | 有机骨架包裹发光心脏，左右巢口形成对称结构 | 放射脉冲、地面爬行者与间歇能量弹 | 先清地面威胁，再抢心脏暴露窗口；最后阶段提高节奏，维持可穿行的弹幕空隙 |

关卡数据中的 Boss 血量依次为 `100 / 130 / 165 / 190 / 210 / 240 / 275 / 330`。后续平衡调整应根据实际默认武器的击杀时间进行，不能只增加血量来制造难度。

## 通行和公平性约束

所有难度均以 30 条命开始，无需输入秘籍。通关后保留剩余命数与已持有武器；生命耗尽后选择重新挑战，会以 30 条命重新开始当前关。辅助难度另有 3 格装甲，经典与老兵难度仍为一击倒下。双人模式共享当前战役的命数，拾取生命补给会增加共享余量。

横向关卡的必经地面为连续分段，坑宽统一为 3 米；跳跃速度 13、重力 28 时的最高点约为 3 米。上层平台通常相差 2.1 米，瀑布为 2.2 米，均低于跳跃极限。每组火焰、电弧或压机前后留有站立区，玩家可以观察周期后通过。额外生命通常放在可选高台上。

横向复活点位于地面段起始的安全脚点。瀑布复活点分别在 0、22、44、66 米处，并位于足够宽的平台上。Boss 前保留宽平台，避免玩家在读取新攻击时被要求同时进行极限跳跃。

平台坐标使用左端 `x`、顶面 `y`，平台实体向下延伸 `h`；玩家和地面敌人的 `y` 是脚底。机关的 `x/y` 是伤害区域左下角，`h` 向上，周期与相位以秒计。基地横坐标在 `-9..9`，核心高度为 `1.3 / 3.1 / 4.8`，核心墙深度由引擎统一设置。关卡文件没有读取网络或执行外部脚本。

已使用实际游戏引擎的 60 Hz 更新进行独立物理检查：瀑布通过连续方向与跳跃输入完成 35 层攀升，脚底从 0 到 77 米；五个横向关卡的 31 个必经地面坑逐一验证落地；首关 Boss 可由制式步枪击毁。通行检查隔离了敌人与机关伤害，Boss 检查让测试角色免伤，以分别验证地形可达性与武器命中，因此这些结果不等同于完整战斗难度测试。三个难度的单人、双人组合均验证了起始 30 命、跨关保留余量、重新挑战恢复 30 命。
